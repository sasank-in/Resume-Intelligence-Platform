# 📖 User Guide - Resume Analyzer Pro

## 🎯 Two Powerful Tools

**Resume Analyzer Pro** provides two independent tools to optimize your job search:

- **Analyzer**: Upload and analyze your resume with AI insights
- **Find Jobs**: Research job market and analyze job descriptions (no resume needed)

---

## 🚀 Getting Started

### **Tool 1: Resume Analyzer**
1. Go to **Analyzer** (homepage)
2. Upload your PDF resume
3. Get instant AI analysis and insights
4. Chat with AI about your career

### **Tool 2: Find Jobs**
1. Go to **Find Jobs** page
2. Paste any job description to analyze
3. Get market insights for any role
4. No resume upload required

---

## 🔍 Features Explained

### **Resume Analyzer Tool**
**What it does:** Complete resume analysis with AI
- Extracts skills, experience, education
- Provides professional insights and recommendations
- Interactive chat about your career
- LinkedIn integration for enhanced profiles

**Best practices:**
- Use text-based PDFs (not scanned images)
- Include complete work descriptions
- List specific skills and technologies

**How to use:**
1. Click **Analyzer** in navigation
2. Upload your PDF resume
3. Review AI analysis results
4. Use chat feature for specific questions

### **Find Jobs Tool**
**What it does:** Job market intelligence without resume upload
- Analyzes job descriptions and requirements
- Provides salary and market data
- Shows career progression paths
- ATS optimization tips

**Features:**
- **Job Description Analyzer**: Paste job posting → Get detailed breakdown
- **Market Insights**: Enter role → Get salary data and market trends
- **Skills Analysis**: See what skills are in demand
- **Career Guidance**: Understand role requirements and progression

**How to use:**
1. Click **Find Jobs** in navigation
2. **Option A**: Paste job description for analysis
3. **Option B**: Enter job role for market insights
4. Get comprehensive data without uploading anything

## 💡 Tips for Best Results

### **Resume Analyzer Tips:**

## 🎯 Common Workflows

### **Workflow 1: Resume First**
1. **Analyzer** → Upload resume → Get AI insights
2. **Find Jobs** → Research target roles → Compare requirements
3. **Analyzer** → Update resume based on job insights
4. Apply to positions with optimized resume

### **Workflow 2: Job Research First**
1. **Find Jobs** → Analyze target job descriptions
2. **Find Jobs** → Research salary and market data
3. **Analyzer** → Upload resume → See how you match
4. **Analyzer** → Use AI chat to improve weak areas

### **Workflow 3: Market Research**
1. **Find Jobs** → Enter different job titles
2. Compare salary ranges and requirements
3. Identify high-demand skills to develop
4. **Analyzer** → Check if your resume highlights these skills

## 🔧 Troubleshooting

### **Analyzer Issues:**
- **"Upload failed"** → Check file size (under 10MB) and format (PDF)
- **"Analysis failed"** → Verify GROQ_API_KEY is set correctly
- **"No insights"** → Ensure PDF has selectable text (not scanned)

### **Find Jobs Issues:**
- **"Analysis incomplete"** → Paste complete job descriptions
- **"No market data"** → Try different job title variations
- **"Loading forever"** → Check internet connection

### **General Issues:**
- **Navigation not working** → Clear browser cache and refresh
- **Pages not loading** → Ensure server is running on correct port
- **Features missing** → Check that all files are properly updated

2. **Ask specific questions** like "How can I improve my technical skills section?"

### **Combined Strategy:**

2. **Analyze your resume** to see current position
